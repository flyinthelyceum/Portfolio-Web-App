# Generative Color Studies

## The Question

Can I build a system that generates visually cohesive color palettes using only mathematics?

## The System

Using sine and cosine waves in HSB color space, I created a generator that produces infinite color palettes. Each palette is defined by a few parameters:

* **Base hue**: The starting point on the color wheel
* **Saturation curve**: How intense each color is
* **Brightness variation**: How light or dark the overall palette feels
* **Wave frequency**: How quickly the hues shift

## Why This Works

Human eyes find color harmony in patterns. By using periodic functions (sine waves), I'm creating mathematical relationships that feel natural to our visual system. It's like discovering that nature already "knows" about good design.

The surprising part: changing a single parameter can completely transform the feel of a palette. Increase the frequency slightly, and what felt calm becomes energetic.

## Application

These palettes feed into other generative systems. They're the foundation for color animation, data visualization, and interface design experiments.

The beauty of this approach is reproducibility—every palette can be generated from a set of numbers, making it perfect for parametric design.
