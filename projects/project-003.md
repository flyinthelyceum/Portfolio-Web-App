# Neural Paintings: Algorithms as Co-Creators

## The Question

Can an algorithm be a collaborator rather than a tool? What happens when we cede some creative control to systems we don't fully understand?

## The Process

Using pre-trained neural networks (specifically style transfer and generative models), I create a back-and-forth dialogue:

1. **I make a gesture**: Paint something, photograph something, draw something
2. **The algorithm responds**: Transforms my input using neural processing
3. **I react**: Incorporate the algorithm's output and feed it back in
4. **Loop continues**: We build increasingly complex artifacts together

## What I Discovered

The algorithm doesn't think like me. It finds patterns I wouldn't see. Sometimes the result is beautiful, sometimes it's unsettling. The unsettling moments are often the most interesting.

There's also an undeniable element of surprise. I can't fully predict what the system will do, which means I'm actually *creating with* rather than *creating through* technology.

## Technical Stack

* **TensorFlow.js**: For browser-based neural networks (no external servers)
* **Custom training**: Fine-tuning models on my own aesthetic
* **Real-time processing**: Immediate feedback between human and algorithm

## The Larger Conversation

This work engages with questions about creativity, authorship, and what we mean by "artist." If an algorithm contributed significantly to the final piece, who gets credit?

I don't have a definitive answer, but the question is worth sitting with.

## Future Exploration

* Train models specifically on my visual language
* Collaborative pieces with other artists + neural networks
* Performance versions where the creation happens in real-time
