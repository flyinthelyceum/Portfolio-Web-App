# LEXICON.md

This document defines the product language so UI copy stays clean and consistent.

## Core nouns (canonical)
- Task (singular)
- Tasks (plural)
- Log Work (verb + noun)

## What a Task is
A teacher-authored prompt container.
A Task always belongs to a category.

Students do not create Tasks.

## What Log Work is
A student’s response to a Task.
One Log Work per Task per day.

Log Work can be Draft or Published.

## Categories (v1 defaults)
- Office Hours
- News
- Project
- Chore
- Ritual

## ISRU mapping (for internal reference)
- ISRU “Challenge” → Task
- ISRU “+ Today’s Entry” → Log Work
- ISRU “Highlights” → Highlights
- ISRU “Leaderboard” → Leaderboard
- ISRU “Excellence Awards” → Features
- ISRU “ID Badge” → ID Card (Profile Card)

## UI language rules
- Use “Log Work” as the primary verb (not “post”).
- Use “Task” everywhere, even if the UI card name changes later.
- “Preview Portfolio” is allowed, but buried.
- “Critique” never appears in the app UI (critique is external).
