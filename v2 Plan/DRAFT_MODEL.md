# DRAFT_MODEL.md

Drafts protect momentum without forcing publicity.

## States
- Draft
- Published
- Archived (optional, teacher/admin)

## Draft rules
- Drafts earn 0 points.
- Drafts are visible only to the author and teacher/admin.
- Drafts can be edited freely.
- Drafts can be deleted by the author.

## Publish rules
- Publishing awards points once (based on Task pointsPerLog).
- Publishing makes the Log Work eligible for:
  - likes
  - comments
  - highlights
  - Features
- Publishing can be reversed (unpublish) only if:
  - within a short window, or
  - teacher/admin approves (optional policy)

## Revision behavior (preferred)
If one log per Task per day is enforced:
- allow edits to the published log for that Task/day
- treat as revisions, not new entries
