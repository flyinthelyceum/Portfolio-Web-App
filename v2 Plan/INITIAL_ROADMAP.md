# INITIAL_ROADMAP.md — Course Architecture Alignment (Updated)

## What This Document Is
This explains how the portfolio app aligns to your course architecture.

The app is not a standalone product.
It is an infrastructural layer inside a teaching system.

## What the Initial Roadmap Produces
The Initial Roadmap is a framework that generates course architecture (not lesson plans),
and informs:
- course style guide (voice + tone)
- studio operations (daily rhythm)
- critique protocol (external critique posture)
- revision guide (what iteration means)
- assignment templates (structure)
- reference library (taste + seriousness)

## Where Portfolio Practice Fits
Documentation is a daily studio practice:
a witness to attention over time.

The app exists to support that practice by making:
- daily logging easy,
- revision legible,
- participation visible.

## What the Portfolio App Is (and Is Not)
The app is:
- a structured practice tool (Tasks + Log Work)
- a persistent record of revision
- a public-facing portfolio output (secondary)

The app is not:
- an LMS replacement
- a grading interface
- an algorithmic feed
- a “best work only” gallery

## Alignment Principles
### 1) Process Over Polish
The system privileges in-progress work and accumulation.

### 2) Documentation as Practice
Posting should feel like a studio reflex, not a bureaucratic step.

### 3) Revision Visibility
Iteration is not optional. The system should make change easy to show.

### 4) Competition as Momentum (Not Grades)
Competition is allowed and intentional.
Points and leaderboards are a motivational structure, not assessment.

The system should:
- make competition legible,
- keep it bounded and fair,
- allow multiple leaderboard lenses (not only total points),
- avoid manipulative dark patterns.

### 5) Social is Lightweight, Critique is External
In-app interactions are:
- likes
- comments
- teacher Features

Critique remains external to the app.
The app does not become the critique room.

## Implications for Onboarding Language
Onboarding should:
- explain why the practice matters
- teach the Task-first loop quickly
- normalize drafts and incompleteness
- frame points as momentum, not grading
